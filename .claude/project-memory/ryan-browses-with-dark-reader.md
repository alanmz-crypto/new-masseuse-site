Ryan reviews WordPress sites in Google Chrome (profiles 4 and 6, both with Dark Reader 4.9.x) on Arch/KDE with the desktop in dark mode (`prefers-color-scheme: dark`). Dark Reader uses its default synced settings: dynamic theme, enabled for all sites, no localhost exception. Chrome has no dark-mode flags.

When he says a flash is only visible "in dark mode," assume Dark Reader is restyling the page before assuming browser auto-dark or a site dark theme. See [[darkreader-white-flash-causes]].
