Last updated: October 20, 2026. This policy covers Ryan Personal Automation, operated by Ryan Steitz, and its Google Drive connection.

Data access and use

The app uses Google authorization tokens to perform the file operations the account holder authorizes. Depending on the granted Drive permissions and configured task, rclone can read file contents and metadata, list folders, upload or download files, and create, update or delete files. The purpose is personal file backup, synchronization and organization. A sync task can delete destination files when their source files are deleted.

Storage and sharing

Authorization tokens and tool configuration are stored on Ryan’s computer in access-restricted files. Selected files are stored locally and in the authorized Google Drive account. Operational logs may contain file paths, names, transfer results and errors. Anyone with authorized access to a destination folder may be able to access its files.

Google data is used only for the authorized personal workflow. It is not sold, used for advertising or used to train generalized AI models. This Drive backup connection does not send file contents to an AI service. Any future integration that changes data use or sharing requires an updated disclosure and the account holder’s authorization before it is enabled.

Google data and access tokens are not stored on this information website. Visiting these pages is subject to the website’s separate site privacy policy, including ordinary hosting logs.

Retention and removal

Files remain in their configured locations until removed by an authorized user or a configured synchronization task. Logs and local backup copies remain until Ryan removes them; there is no fixed automatic deletion period. Google Drive trash and any separate backups can retain copies after a file is deleted.

The account holder can revoke future access through Google Account connections. Revoking access does not delete files already copied. Contact Ryan to request removal of stored authorization tokens, logs or local copies, or help locating retained copies.

Google API data policy

Ryan Personal Automation’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
