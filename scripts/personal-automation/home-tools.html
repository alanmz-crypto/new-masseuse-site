Ryan Personal Automation is a private set of tools operated by Ryan Steitz for personal tasks and authorized business administration, including Thai Solitude. It is for Ryan and account holders who expressly authorize a workflow. It has no public registration and charges no fee.

What it does

  • Drive, Docs and Sheets: back up and organize selected files, prepare documents, and work with spreadsheets.
  • Gmail, Calendar and Contacts: help with correspondence, scheduling and contact records through the tools the account holder connects.
  • Search Console, when connected: read website search performance, sitemap and indexing information to help maintain Thai Solitude. This connection does not change Search Console settings or publish website changes.

These tools run on Ryan’s computer and may be used through an AI assistant. Selected Google data and the user’s instructions may be sent to the assistant’s provider to carry out the requested task. A file-backup task using rclone does not itself send file contents to an AI service. The privacy policy explains these different uses.

Access and control

Each Google account is authorized separately through Google’s consent screen. Connecting one service does not enable every other service or authorize every action. Sending messages, changing events or contacts, sharing files and publishing content require an authorized task. A configured file sync can replace or delete destination files to match the selected source; a synchronized copy is not a version history.

The account holder can stop using a tool or remove its access in Google Account connections. This website provides information about the tools; it does not ask visitors to sign in, upload files or provide Google credentials. It is separate from Thai Solitude’s public massage-service pages.
