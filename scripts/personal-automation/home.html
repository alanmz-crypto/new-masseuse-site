A private set of personal automation tools operated by Ryan Steitz. The initial Google connection uses rclone to copy and synchronize selected files with an authorized Google Drive account.

What it does

Ryan Personal Automation helps keep selected personal files backed up and organized. It runs on Ryan’s computer; this website provides information about the app and does not ask visitors to sign in or upload files.

Other personal workflows, such as calendar, contact or document tools, may be added separately. Publishing this page does not enable those connections. New uses require appropriate permissions and updated privacy information before access begins.

Access and control

Google access is granted by the account holder through Google’s consent screen. Permissions depend on the tool being connected. Access can be removed in Google Account connections.

Read the Ryan Personal Automation privacy policy.

Personal use

This app is for Ryan and account holders who expressly authorize a personal workflow. It is not offered as a public service, has no public registration and charges no fee. Synchronization can replace or delete destination files to match the selected source; a synchronized copy is not a version history.
