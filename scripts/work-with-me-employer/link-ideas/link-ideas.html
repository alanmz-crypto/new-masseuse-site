In-page link ideas

Five ways to replace the plain “On this page” link row. Pick one, then scroll or tap. Every idea is plain HTML, CSS and a little JavaScript: no plugin, so the same code can go on the real pages.

1. Sticky pills that follow you

A row of rounded buttons that sticks to the top while you read. The green highlight slides to the section you are in, and on a phone the row scrolls sideways.

Built with position: sticky, IntersectionObserver and CSS scroll snap.

2. Progress segments

One short bar per section, like story bars on a phone. Each bar fills as you read that section, and the label says where you are (“2 of 6”). Tap a bar to jump.

Built with position: sticky and a scroll listener throttled with requestAnimationFrame.

3. Topic cards

Big numbered tiles instead of small text links: easy to tap and easy to scan. After you jump, the heading glows briefly, and a “Topics” button appears so you can get back.

Built with CSS grid, the CSS :focus highlight and a scroll listener.

4. Search box (command palette)

A “Find a topic” box. Type a few letters to filter, use the arrow keys and Enter, or tap a result. On a computer, Ctrl+K or ⌘K opens it from anywhere.

Built with the browser’s own <dialog> element.

5. Floating island

A small pill at the bottom of the screen, where the thumb rests. It shows the section you are reading and a ring for progress. Tap it and it opens into the full list.

Built with position: fixed, a CSS grid open/close animation and a scroll listener.
